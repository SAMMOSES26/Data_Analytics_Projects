# 📊 Personal Finance Tracker – Excel Dashboard

## 📌 Project Overview
This project is a **Personal Finance Tracker built using Microsoft Excel** to analyze income, expenses, and spending behavior through an **interactive dashboard**.

The objective of this project is to demonstrate **end-to-end data analysis workflow** — from data preparation and analysis to dashboard design, interactivity, and insight generation.

---

## 🎯 Business Questions Addressed
The dashboard answers the following key questions:

1. What is the **total income**?
2. What are the **total expenses**?
3. What is the **monthly income and expense trend**?
4. What is the **weekly income and expense trend**?
5. What are the **top spending categories**?
6. What are the **income sources**?

---

## 🗂 Step-by-Step Project Workflow

### 1️⃣ Data Preparation & Structuring
- Converted the dataset into **Excel Tables** to ensure structured and scalable data handling
- Verified that the data was **cleaned and standardized** before analysis
- Ensured consistency across:
  - Date formats
  - Income and expense categories
  - Numerical values

---

### 2️⃣ Data Analysis Using Pivot Tables
- Created **Pivot Tables** to aggregate and summarize data for:
  - Total income
  - Total expenses
  - Monthly income and expense trends
  - Weekly income and expense trends
  - Top spending categories
  - Income source distribution
- Used pivot-based calculations to support dynamic analysis and filtering

---

### 3️⃣ Dashboard Wireframing (Pre-Development)
- Designed the dashboard layout **before adding real data, formulas, or charts**
- Used Excel:
  - Cell borders
  - Shapes
  - Text boxes
- Planned the structure and placement of:
  - KPI cards
  - Charts
  - Filters and slicers
- This step ensured a clean layout, proper visual hierarchy, and improved user experience

---

### 4️⃣ Dashboard Development & Visualization
- Built an interactive dashboard by connecting **pivot tables to charts**
- Designed **KPI cards** to highlight key financial metrics:
  - Total Income
  - Total Expenses
  - Available Balance
- Applied consistent formatting, alignment, and spacing for a professional UI
- Downloaded and integrated icons from **Flaticon** to enhance visual clarity

---

### 5️⃣ Interactivity with Slicers
- Added **monthly slicers** connected to pivot tables
- Enabled dynamic filtering of:
  - KPIs
  - Charts
  - Trends
- Allowed users to explore financial insights **without modifying raw data**

---

### 6️⃣ Trend & Insight Analysis
- Analyzed **monthly trends** to identify spending fluctuations over time
- Analyzed **weekly trends** to observe behavioral spending patterns
- Evaluated **spending categories** to identify major expense drivers
- Analyzed **income sources** to assess income distribution and dependency risk

---

---

## 🔍 Key Insights
- Expenses represent ~**46% of income**, leaving a positive balance of ~**54%**, indicating healthy financial management
- Income is highly concentrated, with a single source contributing ~**76%** of total income
- Housing and groceries account for over **50% of total expenditure**, making them the primary cost drivers
